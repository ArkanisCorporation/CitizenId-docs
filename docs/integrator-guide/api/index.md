# Citizen iD API

The Citizen iD API provides programmatic access to user identity data, organization memberships, and integration features.
It is built on REST principles and returns JSON responses.

## OpenAPI Documentation

For comprehensive documentation of all available endpoints, parameters, and response schemas, please refer to our interactive [OpenAPI Documentation](https://citizenid.space/openapi).

## Base URL

All API requests should be made to:

```
https://citizenid.space/api/v1
```

## Content Types

The API accepts and returns JSON.
Ensure you set the `Content-Type` and `Accept` headers to `application/json` in your requests.
