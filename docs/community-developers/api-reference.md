# API Reference

Citizen iD exposes API surfaces for approved integrations.

The current docs link to the live OpenAPI UI, and the documentation stack is being prepared for generated API reference pages.

## Current Path

Use the production OpenAPI UI for the latest live API surface.

[Open the current OpenAPI documentation](https://citizenid.space/openapi).

## Reference Plan

The docs site should publish versioned OpenAPI snapshots generated by CI.

Generated reference pages should mark whether an endpoint is implemented, in development, user-token protected, application-token protected, or integrator-user protected.

Live production scraping should not be required for the docs build.

## Legacy Details

The old API pages remain available while generated reference pages are added.

See [Citizen iD API](/integrator-guide/api/) and [API Authentication](/integrator-guide/api/auth).
