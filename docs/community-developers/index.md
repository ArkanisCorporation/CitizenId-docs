# Community Developer Guide

Developers build tools that integrate with Citizen iD.

The product role that unlocks this surface is still called Integrator.

The docs use Developers as the audience label because it describes who the documentation is for.

## Start Here

- [Request Integrator Access](/community-developers/request-integrator-access) explains the application flow and product role.
- [Applications](/community-developers/applications) explains client records, redirect URIs, secrets, and community-scoped app management.
- [OAuth And OIDC](/community-developers/oauth-and-oidc) explains supported identity protocols and endpoints.
- [Scopes And Claims](/community-developers/scopes-and-claims) explains consent, required scopes, and token claims.
- [Tokens And Revocation](/community-developers/tokens-and-revocation) explains token lifetime, refresh, revocation, and delegation.
- [API Reference](/community-developers/api-reference) explains the current API documentation path and generated reference plan.

## Audience Boundary

Community admins configure Citizen iD for a server or community.

Developers build applications that use Citizen iD as an identity and authorization provider.

If you are both, use the community admin guide for bot and role operations, and this guide for application integration.
