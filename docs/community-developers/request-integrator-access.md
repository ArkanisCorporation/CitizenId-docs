# Request Integrator Access

Integrator is the Citizen iD product role for approved developers.

It unlocks developer portal access and application management.

## Preconditions

You need a Citizen iD account.

You should complete RSI verification when the target community or application review requires it.

You need a linked Discord account when the review process checks official community Discord membership.

You need to accept the Developer Terms before submitting the request.

## Application Contents

The request asks what you intend to build.

It asks which Citizen iD features you plan to use.

It asks which feature targets apply to your integration.

It asks for enough detail for staff or auto-approval rules to decide whether access is appropriate.

## Review States

Requests may be submitted, approved, or rejected.

Some environments may auto-approve requests.

Production access should be treated as reviewed access unless product configuration explicitly says otherwise.
