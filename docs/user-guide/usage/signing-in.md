# Signing In with Citizen iD

Citizen iD functions as a **Single Sign-On (SSO)** provider.
This means you can use your Citizen iD account to log in to various third-party community tools, organization websites, and services without creating a new password for each one.

## The Login Flow

1. **Click "Sign in with Citizen iD"**: On the third-party website, you will see a button to sign in.
2. **Review Permissions**: You will be redirected to the Citizen iD website, where you will see which application is requesting access and what data they want to see (e.g., your profile, your email, your RSI handle).
3. **Authorize**: If you agree to share this information, click **Authorize**.
4. **Redirect**: You will be sent back to the third-party website, now logged in.

## Security

Your password is **never** shared with the third-party application.
They only receive a secure token that allows them to access the specific information you authorised.
