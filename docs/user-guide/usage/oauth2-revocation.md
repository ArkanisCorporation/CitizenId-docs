# Revoking Authorization

If you no longer want an application to access your Citizen iD data, you can revoke its authorization at any time.

## How to Revoke Access

1. Log in to your [Citizen iD Authorized Apps](https://citizenid.space/account/apps).
2. Find the application you wish to disconnect.
3. Click the **Details** button.
4. Click the **Revoke Authorization** button.

## What Happens Next?

The application's access tokens are immediately invalidated and it can no longer access your profile or data.
If you try to log in to that application again, you will be asked to re-authorize it from scratch.

> [!WARNING]
> Revoking access does not delete any data the application may have already collected and stored on its own servers up to that point.
> If you wish to have your data deleted, you should contact the application's support team to request it.
