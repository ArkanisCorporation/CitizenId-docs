# Common Issues

## RSI Verification Not Syncing
If your dashboard says "Verified" but your Discord roles haven't updated:
1. Ensure your Discord account is linked in your profile settings.
2. Check if you have joined the specific Discord server.
3. Try using the `/roles update` command in the server.

## "Account Already Linked" Error
This means your RSI account or Discord account is already connected to another Citizen iD profile.
To resolve this:
- Log in with the other Discord account and unlink the RSI handle.
- If you have lost access to the old account, please contact support.

## Endless Login Loop
If you click "Sign In" and are immediately redirected back without logging in:
- Clear your browser cookies for `citizenid.space`.
- Disable any strict privacy extensions that might block authentication cookies.
- Ensure your system clock is synchronized.
