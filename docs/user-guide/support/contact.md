# Contact & Support

We are here to help! If you encounter any issues or have questions, please reach out to us.

## Official Discord Server
The fastest way to get help is through our [Community Discord](https://discord.citizenid.space).
- **Public Discussion**: Join `#general` for [public discussion](https://discord.com/channels/1401938319843004416/1402167827192090664).
- **Q/A & Help**: Use the `#forum` for [Q/A and targeted public help](https://discord.com/channels/1401938319843004416/1406283048038961193).
- **Private Support**: Open a ticket in `#support-and-contact` for [sensitive information and official matters](https://discord.com/channels/1401938319843004416/1401942231707029505).

## What to Include
When asking for help, please provide unique identifiers where relevant:
- **Citizen iD Profile Link** (accessible from user menu under avatar),
- **Email** or **Username**,
- **RSI Handle**,
- a clear description of the issue,
- screenshots of any issues.
