# Authorized Apps

When you sign in to a community tool with Citizen iD, that tool asks for permission to access specific parts of your account.

That permission is stored as an authorization.

## What To Review

Review which application you approved.

Review which scopes were requested.

Review whether the application can keep access with refresh tokens.

Review whether any required scopes are blocking the sign-in until you provide missing account data.

## Revoking Access

You can revoke an application's access from the authorized apps area of your Citizen iD account.

Revocation stops that application from continuing to use the authorization.

If you use the same application again, it may ask you to approve access again.
