# Privacy And Data

Citizen iD is built around explicit identity sharing.

Players should know which data is public, which data is shared through application consent, and which data stays private.

## Public Profile Discovery

Public profile discovery controls whether other people can find your Citizen iD profile.

External-account discovery controls whether linked external accounts can be used to discover your profile.

If discovery is disabled, public lookups can return a not-found result even when the account exists.

## Application Consent

Applications receive only the data covered by the scopes you approve.

Required scopes may block sign-in until the required account data exists.

Optional scopes can be omitted when the data is missing or when you do not approve them.

## Analytics Consent

Citizen iD analytics are consent-gated.

Do Not Track can force analytics rejection.

Analytics consent is stored locally in the browser.

## Data Export And Deletion

Citizen iD supports personal data export.

The export can include account metadata, linked accounts, community data, RSI data, OAuth metadata, Discord nickname data, and export metadata.

Account deletion is currently request-only.

Self-service deletion is intended, and this page should be updated when the product flow is available.
