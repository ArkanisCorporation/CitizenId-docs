# Discord Linked Roles

Discord linked roles let a server use Citizen iD facts when deciding whether you can claim a Discord role.

Those facts can include Citizen iD status, public profile settings, RSI verification, and Discord-linked state.

## Player Flow

Open the server role menu in Discord.

Choose a role that uses Citizen iD linked-role requirements.

Authorize Citizen iD when Discord sends you through the connection flow.

Return to Discord and claim the role after the requirements are satisfied.

## Privacy Behavior

Citizen iD only shares the metadata needed by Discord for the linked-role check.

Public profile and external-account discovery settings affect what other people can discover about your account.

If your account is not verified, Citizen iD can warn you before Discord role metadata is considered complete.
