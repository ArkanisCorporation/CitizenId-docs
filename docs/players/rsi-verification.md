# RSI Verification

RSI verification connects your Citizen iD account to your Star Citizen identity.

Communities and tools can then rely on Citizen iD instead of asking you to repeat manual screenshot checks.

## How Verification Works

Citizen iD asks for your RSI handle.

Citizen iD generates a verification string.

You place that string in your RSI profile short bio.

Citizen iD checks the public RSI profile and confirms that the expected string is present.

After verification succeeds, you can remove the temporary string from your RSI profile.

## Important Limits

A Citizen iD account is intended to be linked to one RSI account.

Verification may fail if the handle is wrong, the RSI profile cannot be reached, or the verification string is missing from the short bio.

Some Citizen iD features can be skipped or used before RSI verification, but communities may require verified status before granting roles or application access.
