# Reference

Reference pages support all three audiences.

They contain stable facts, shared checklists, brand rules, legal pointers, and operational notes that do not belong to only one guide.

## Reference Areas

- [Brand Guidelines](/reference/brand-guidelines) points to the current Citizen iD brand usage guide.
- [Legal And Privacy](/reference/legal-and-privacy) summarizes legal document surfaces and privacy-related docs.
- [Support Evidence](/reference/support-evidence) lists the evidence users, admins, and developers should collect before escalation.
- [Operations Notes](/reference/operations-notes) records public operational behavior and deployment documentation boundaries.

## Migration Note

Some reference content still lives under the old integrator guide while the docs are being migrated.

The new reference area is the public home for shared content going forward.
