# Maintenance And Support

Community admins need operational tools as much as configuration tools.

Citizen iD supports community-scoped maintenance and role-assignment audit trails.

## Maintenance Windows

Community-scoped maintenance can target community-managed modules.

Maintenance windows have start and end times, enabled state, and audience targeting.

Platform-locked maintenance rows are controlled by staff and cannot be changed by community admins.

## Support Evidence

When escalating an issue, collect the affected member, community slug, UTC timestamp, request ID if present, role-assignment audit entry if relevant, and Discord server context.

For role issues, include whether the member used manual resync and whether the bot has the required Discord permissions.

For nickname issues, include the template fields and the nickname the bot attempted to apply.
