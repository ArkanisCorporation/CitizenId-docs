# Community Admin Guide

Citizen iD helps community admins operate identity-aware Discord and community workflows.

This guide separates community administration from community development.

Use it when you manage a community, configure the Citizen iD bot, maintain role automation, review audit logs, or support members.

## Start Here

- [Community Setup](/community-admins/community-setup) explains community records, slugs, parent communities, and staff-managed details.
- [Discord Bot](/community-admins/discord-bot) explains bot installation, permissions, tabs, and expected synchronization delays.
- [Role Assignments](/community-admins/role-assignments) introduces templates, conditions, targets, preview, audit logs, and resync.
- [Nickname Management](/community-admins/nickname-management) explains template-based Discord nickname automation.
- [Branding Assets](/community-admins/branding-assets) explains community-owned visuals and review status.
- [Maintenance And Support](/community-admins/maintenance-and-support) explains maintenance windows, audit evidence, and escalation.

## Community Admins And Developers

Community admins manage a community's operational setup.

Developers build tools that integrate with Citizen iD through OAuth, OpenID Connect, and APIs.

Some people do both, but the docs keep the workflows separate so each path stays readable.
